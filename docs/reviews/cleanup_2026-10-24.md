## Compatibilidad conservada

- Formato de guardado 5, IDs de escenas, niveles, vocabulario y claves de checkpoints.
- UID de los scripts movidos y recursos de escena existentes.
- API y señales de `GameManager`, junto con adaptadores usados por herramientas históricas.
- Contextos de variación de diálogos previos a la reorganización, ahora explícitos.
- Las 48 geometrías, 28 combinaciones y 1392 textos existentes. Los manifiestos
  trasladan la autoría a una fuente reproducible; no agregan contenido jugable.
- Arte compartido y sus rutas. Las pruebas de regresión usan datos aislados.

Los dos scripts de compatibilidad `WordPathLevel.gd` y `GridAnimalData.gd`
conservan sus rutas históricas para consumidores externos. No se eliminaron por
tener poco contenido. Las demás referencias del repositorio utilizan el árbol nuevo.

## Validación

Con Godot 4.6.3 se ejecutó la importación y la batería completa: **25/25 suites
aprobadas**, sin errores ni advertencias del motor. Las 24 suites originales se
conservaron y se agregó `tests/unit/validate_architecture.gd`.

La última ejecución completa, posterior al ajuste de las reglas de sesión,
también terminó con **25/25 suites aprobadas**. Los tres generadores pasan
`--check` y el formateador pasa `-Check`.

Una copia independiente sin caché del motor pasó la importación, la suite de
arquitectura y la comprobación de firmas. La revisión estática verificó 655
referencias físicas y 124 UID de scripts. La comparación con Git confirmó los
82 UID de scripts movidos y los 19 UID de escena presentes originalmente; los
manifiestos coinciden con el contenido previo.

Los registros locales están en `.ui-review/final-validation.log`,
`.ui-review/clean-import.log`, `.ui-review/format-check.log` y
`.ui-review/path_migration.json`. El informe conserva las decisiones y resultados
necesarios aunque esos archivos de diagnóstico no se versionen.

## Límites y decisiones de mantenimiento

La separación se realizó conservando adaptadores para la API histórica. Los
controladores todavía contienen representación propia de cada actividad y
varias pruebas de integración acceden a detalles internos históricos. Las
reglas nuevas se prueban con objetos sin nodos; no se reescribieron todas las
pruebas existentes para cambiar de infraestructura.

El generador de tableros compila el manifiesto revisado. El algoritmo histórico
de búsqueda no estaba disponible y no se presenta como recuperado. Crear nuevas
geometrías sigue siendo una tarea de autoría con sus soluciones y métricas.

No se ejecutaron exportaciones a dispositivos físicos ni el flujo remoto de
GitHub Actions. Esas comprobaciones se realizan al preparar las plataformas de
publicación y al subir los cambios, respectivamente.

La referencia vigente es [Arquitectura](../architecture.md); los comandos están
en [Mantenimiento](../maintenance.md).
