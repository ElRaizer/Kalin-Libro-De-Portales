# Archivos de audio del vocabulario maya

Coloca aquí los archivos de audio en formato `.ogg`.

## Convención de nombres
El script elimina apóstrofes y espacios del nombre maya para generar el nombre del archivo:

| Palabra maya | Archivo .ogg      |
|--------------|-------------------|
| Peek'        | Peek.ogg          |
| Miis         | Miis.ogg          |
| Kaax         | Kaax.ogg          |
| Aak'         | Aak.ogg           |
| Keej         | Keej.ogg          |
| K'eek'en     | Keeken.ogg        |
| Maax         | Maax.ogg          |
| Tuut         | Tuut.ogg          |

## Cómo grabar / convertir
- Graba en MP3 o WAV y convierte a OGG con **Audacity** (Exportar > OGG Vorbis)
- O usa servicios online como cloudconvert.com
- Calidad recomendada: mono, 22050 Hz, calidad 3

Una vez que coloques el archivo en esta carpeta y lo importes en Godot,
el botón "Escuchar" en el Libro de Hechizos lo reproducirá automáticamente.
